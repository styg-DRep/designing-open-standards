## Intent

Actively search for alternatives to creating a new standard.

The desired outcome of scoping is not necessarily permission to proceed.

Ask:

- Can an existing standard already satisfy the use cases?
    
- Can a process change solve the problem?
    
- Can better documentation solve it?
    
- Can interoperability between existing tools solve it?
    
- Is the perceived standards problem actually a participation, governance or infrastructure problem?
    
- Would adoption work accomplish more than specification work?
    

## Pattern: Earn the right to create

A new standard should survive an explicit search for reasons **not** to create it.

`no new standard required` is a successful possible outcome of this node.
