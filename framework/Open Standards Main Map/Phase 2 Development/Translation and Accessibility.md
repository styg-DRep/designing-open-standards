## Intent

Make each class of documentation reachable by the people (and machine agents) who need it, in the language, level, format and bandwidth they can use, while keeping clear correspondence with the canonical version.

For each documentation class ask:

- Who needs it?
    
- In what language?
    
- At what technical level?
    
- In what format?
    
- With what accessibility requirements?
    
- Can low-bandwidth users access it?
    
- Can machine agents consume relevant reference material?
    

Translation should preserve clear correspondence with the canonical version.
