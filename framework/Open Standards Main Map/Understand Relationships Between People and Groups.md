## Intent

Understand how actors depend upon, constrain, influence and exchange information with one another.

An actor inventory without relationships is not yet an ecosystem map.

Look for relationships such as:

- provides information to;
    
- depends upon;
    
- delegates to;
    
- funds;
    
- governs;
    
- implements;
    
- verifies;
    
- interprets;
    
- contests;
    
- represents;
    
- maintains infrastructure for;
    
- amplifies;
    
- blocks;
    
- certifies;
    
- supplies evidence to.
    

Do not assume formal authority describes actual influence.

## Working pattern: Follow the dependency

For each important governance activity ask:

> What must already exist for this actor to do this?

Then follow the dependency backward.

For example:

> A voter can evaluate a proposal  
> because proposal information is available  
> because someone publishes it  
> through an interface  
> using some schema  
> maintained by someone  
> under some governance arrangement.

This often exposes the actual intervention surface for a standard.
