## Intent

Determine whether an existing standard already provides a viable foundation.

Ask:

- Does an existing standard solve most of the problem?
    
- Could additional fields, vocabulary, guidance or interfaces address the remaining need?
    
- Would extension preserve interoperability?
    
- Who maintains the original?
    
- Is extension technically and institutionally possible?
    
- Would an extension fragment the ecosystem?
    

## Pattern: Prefer continuity where continuity serves

Creating a new standard creates another thing the ecosystem must understand, adopt and maintain.

Prefer extension when it preserves useful shared structure without forcing materially different needs into an unsuitable model.
