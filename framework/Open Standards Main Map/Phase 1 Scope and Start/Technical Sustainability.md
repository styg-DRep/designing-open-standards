Ask whether the standard depends on technology or infrastructure that can plausibly persist.

Consider:

- external APIs;
    
- repositories;
    
- domains;
    
- registries;
    
- identifiers;
    
- libraries;
    
- reference implementations;
    
- validators;
    
- schemas;
    
- hosted services.
    

Ask:

> What happens if the current maintainer disappears?

Prefer:

- portable artifacts;
    
- open formats;
    
- reproducible tooling;
    
- public archives;
    
- minimal critical dependencies.
    

---

# Pattern: The Standard Must Survive Its Website

A durable open standard should not cease to exist because:

- a repository disappears;
    
- a domain expires;
    
- a hosted validator stops running;
    
- one company closes.
    

Important artifacts should be independently retrievable and reproducible.
