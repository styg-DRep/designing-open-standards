## Intent

Identify the infrastructure through which governance information and action move.

Infrastructure includes more than software.

Consider:

- on-chain structures;
    
- APIs;
    
- metadata formats;
    
- repositories;
    
- websites;
    
- forums;
    
- wallets;
    
- governance interfaces;
    
- indexes;
    
- identifiers;
    
- registries;
    
- schemas;
    
- voting infrastructure;
    
- archives;
    
- social channels;
    
- recurring meetings;
    
- human moderation practices;
    
- institutional processes.
    

## Working pattern: Trace one governance object

Choose an important governance object and follow it through the ecosystem.

For example:

**proposal → publication → discovery → interpretation → deliberation → decision → implementation → historical record**

At every transition ask:

- What system carries it?
    
- What changes its representation?
    
- Who controls that transition?
    
- What information is lost?
    
- What assumptions must be shared?
    
- What standards already apply?
