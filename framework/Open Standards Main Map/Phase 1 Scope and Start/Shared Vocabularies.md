## Intent

Create shared meaning so that different participants can refer to the same concepts consistently.

A shared-vocabulary standard is useful when coordination is breaking down because people:

- use different words for the same thing;
    
- use the same word for different things;
    
- classify the same objects differently;
    
- lack shared identifiers;
    
- disagree about relevant relationships;
    
- cannot compare information because concepts are modeled differently.
    

## Governance-native forms

A shared-vocabulary standard might define:

- governance concepts;
    
- proposal categories;
    
- decision types;
    
- participation roles;
    
- risk classifications;
    
- outcome classifications;
    
- status vocabularies;
    
- identifiers;
    
- governance object models;
    
- relationships between governance entities.
    

## Discovery questions

Ask:

- Are participants arguing partly because they mean different things?
    
- Are equivalent governance objects described inconsistently?
    
- Do multiple tools classify the same thing differently?
    
- Are important concepts implicit rather than defined?
    
- Would shared identifiers improve interoperability?
    
- Is a common model needed before technical exchange is possible?
