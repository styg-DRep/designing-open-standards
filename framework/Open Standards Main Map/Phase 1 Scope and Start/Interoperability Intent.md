## Intent

Determine where success requires the proposed standard to work coherently with existing standards, tools, vocabularies, identifiers, or infrastructure.

Ask:

- What already exists that should be reused?
    
- What systems must exchange information with this standard?
    
- What identifiers are already authoritative?
    
- Which vocabularies should remain canonical?
    
- What formats are already broadly supported?
    
- Where would incompatibility create adoption costs?
    

## Pattern: Interoperability Is a Relationship

Do not treat interoperability as a generic quality like “good documentation.”

Always name:

> **interoperable with what, for what purpose?**
