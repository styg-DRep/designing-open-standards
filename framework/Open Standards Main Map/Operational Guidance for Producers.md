If the standard relies on participants producing governance information, specify enough operational guidance to keep implementations useful.

Consider:

- when information should be produced;
    
- how quickly updates should appear;
    
- how freshness is communicated;
    
- where information should be discoverable;
    
- how provenance is preserved;
    
- how corrections are issued;
    
- what historical versions remain available;
    
- what consistency is required between producers.
    

For governance information, this might apply to:

- proposal records;
    
- rationales;
    
- votes;
    
- treasury reporting;
    
- implementation status;
    
- constitutional interpretations;
    
- standards registries.
    

A perfectly specified schema can still produce unusable governance information if producers publish it inconsistently or too late.
